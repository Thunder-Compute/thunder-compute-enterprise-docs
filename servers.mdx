## Getting started

Thunder's software runs on each GPU server and connects it to the other machines in its zone. The Thunder dashboard is used to manage zones and authorize new servers.

Before continuing, review the [server requirements](/requirements#server-requirements), including the required network access, and install the pinned NVIDIA driver and patched kernel module described in [NVIDIA driver setup](/nvidia-driver).

## Dashboard

Before setting up a server, open the **Zones** tab and create a zone or select an existing one. You will choose this zone when authorizing the server.

You do not need to set `THUNDER_API_TOKEN` for the setup below. `THUNDER_API_TOKEN` is the management API credential used by trusted automation and is not accepted by the server installer.

## Setup on the node

<Tabs>
  <Tab title="Installer">
    After configuring the firewall, SSH into the server and install the Thunder binaries:

    ```bash
    curl -fsSL https://get.thundercompute.com/install.sh | sudo sh
    ```

    Then start the setup process:

    ```bash
    sudo thunder up
    ```

    The command prints an authorization URL. Open it in your browser, sign in to the dashboard, and choose the zone and IP address for the server.

    After authorization, `thunderd` manages the server and it should appear as active in the dashboard. Run `sudo thunder status` to check its health. If it reports an issue, follow the **Next** action in the output. Use `sudo thunder update` if the output reports missing or outdated binaries.

## Uninstalling

Move active workloads away from the server before removing Thunder. Then run the installed uninstaller:

```bash
sudo /usr/local/bin/uninstall-thunder.sh
```

The uninstaller stops `thunderd`, revokes its node credential, and removes the Thunder service, binaries, configuration, and runtime files from the server.

To also revoke the server through the management API and remove it from active rosters, call the following with the server ID shown in the dashboard. This requires the **Revoke servers** claim (`hosts:revoke`).

```bash
curl --fail-with-body -sS -X POST \
  "https://api.thundercompute.com:2096/api/v1/hosts/<server_id>/revoke" \
  -H "Authorization: Bearer $THUNDER_API_TOKEN"
```
