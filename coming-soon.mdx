## Public Helm chart

Kubernetes deployments currently install from a chart directory supplied by
Thunder. We are publishing the `thunder-device-plugin` chart to a public Helm
repository, so installs and upgrades become a standard `helm repo add` followed
by `helm upgrade --install`, with versioned releases and documented values.

Until then, follow [Kubernetes](/kubernetes) for the current install path.
