## Getting started

Thunder's software runs on each GPU host and connects it to the other machines in its zone. The Thunder dashboard is used to manage zones and authorize new hosts.

If you have not created an account yet, visit [app.thundercompute.com](https://app.thundercompute.com/) and log in. We do not offer self-service onboarding at the moment, so if you cannot access your organization after being invited, contact [support@thundercompute.com](mailto:support@thundercompute.com).

## Dashboard

Before setting up a host, open the **Zones** tab and create a zone or select an existing one. You will choose this zone when authorizing the host.

You do not need to create an API token for the setup below. API tokens under **Authentication** are intended for management API automation and are not accepted by the host installer.

## Network requirements

The GPU hosts need the following network access:

### Ingress

| Port | Reason |
| --- | --- |
| `32000-32199` (TCP and UDP) | Communication between hosts in the same zone and client-facing GPU traffic. Scope this range to the host and client networks in the zone. |

### Egress

| Port | Reason |
| --- | --- |
| `2096` (TCP) | Registration, heartbeat, check-in, and telemetry traffic to Thunder's control plane. |
| `443` (TCP) | Downloading and updating the `thunderd`, `thunder`, and `libthunder` binaries from `get.thundercompute.com`. |

## Setup on the node

After configuring the firewall, SSH into the host and install the Thunder binaries:

```bash
curl -fsSL https://get.thundercompute.com/install.sh | sudo sh
```

Then start the setup process:

```bash
sudo thunder up
```

The command prints an authorization URL. Open it in your browser, sign in to the dashboard, and choose the zone and IP address for the host.

After authorization, `thunderd` manages the host and it should appear as active in the dashboard. Run `sudo thunder status` to check its health. If it reports an issue, follow the **Next** action in the output. Use `sudo thunder update` if the output reports missing or outdated binaries.
