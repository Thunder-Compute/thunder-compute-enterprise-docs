GPU allocation and GPU utilization are different. A workload can hold a GPU for hours while using it only intermittently, leaving valuable compute capacity unavailable to everything else.

Thunder Compute decouples workloads from individual GPU servers. More workloads can be admitted than there are physical GPUs because Thunder assigns an available, compatible GPU only when a workload needs one. This is **GPU oversubscription**.

## How it works

Thunder installs a lightweight library with each client workload and a managed service on each GPU host. When a workload begins using CUDA, Thunder selects available capacity on a compatible host in the same zone and forwards the required CUDA driver operations over the zone's network. The workload continues to use ordinary CUDA APIs and does not need to be recompiled for Thunder.

A physical GPU is assigned exclusively to one workload at a time. When every process in that workload has released its CUDA resources or exited, Thunder can make the GPU available to another workload.

## Choose an oversubscription ratio

The oversubscription ratio is the number of admitted workloads divided by the number of physical GPUs. Six workloads backed by four GPUs is a ratio of `1.5x`.

Higher ratios increase effective fleet capacity, but they also increase the chance that a workload must wait for a GPU. The appropriate ratio depends on workload concurrency, utilization patterns, network performance, and the service-level objective for the fleet.

In Thunder Compute's first-party cloud, aggregate demand from independent workloads has typically supported ratios between `1.2x` and `1.5x`. Treat that range as operational experience, not a universal default: start conservatively, measure queueing and utilization, and adjust the ratio using your own workload data.

## Deployment model

A fleet can span multiple data centers or network regions. Thunder divides it into **zones**, and GPU data-plane traffic never crosses a zone boundary. Keeping clients and hosts close to one another limits latency and contains operational failures.
