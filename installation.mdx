## Deployment requirements

- Supports bare metal or virtualized fleets.
- Supports fleets across multiple data centers. we dynamically detect which workloads are in the same data center and restrict workloads to only use nearby GPUs to maximize performance
- GPU access stays within the same data center due to latency requirements.
- Requires at least 3 GPU servers per data center.
