Review these requirements before creating a server or client.

For CUDA feature support and known limitations, also review [Compatibility](/compatibility).

## Server

| Area | Requirement |
| --- | --- |
| Placement and performance | Must be in the same zone as its clients. For best performance, use a network with round-trip latency below `2 ms` and throughput above `5 Gbps`. |
| System | NVIDIA GPU; NVIDIA driver 610 or newer (Thunder pins `610.43.02`); root or `sudo` access; `curl` and `wget` in `PATH`; `dkms` and matching kernel headers installed. |
| CUDA memory | Mapped, pinned, and managed memory (`cudaHostAlloc`, `cudaMallocManaged`, and Driver API equivalents) requires the Thunder-patched NVIDIA GPU driver. Without it, only these allocation types fail. See [NVIDIA driver setup](/nvidia-driver) to install it. `cudaHostRegister` is emulated and never provides full unified memory, even with the patched driver. See [Compatibility](/compatibility). |
| Ingress | `32000-32199` over TCP and UDP for same-zone server communication and client-facing GPU traffic. Scope access to the zone's server and client networks. |
| Egress | `443` over TCP to `registry.thundercompute.com` for registration, heartbeat, check-in, and telemetry; to `get.thundercompute.com` to download and update `thunderd`, `thunder`, `libthunder`, and the patched NVIDIA GPU driver package; and to `developer.download.nvidia.com` for the pinned NVIDIA driver. |

## Client

| Area | Requirement |
| --- | --- |
| Placement and performance | Must be in the same zone as its servers. For best performance, use a network with round-trip latency below `2 ms` and throughput above `5 Gbps`. |
| System | Linux on `x86_64`; root or `sudo` access; `curl`, `sha256sum`, `install`, and `sed` in `PATH`. No local NVIDIA driver or GPU is required. |
| Ingress | None required by Thunder. |
| Egress | `443` over TCP to `registry.thundercompute.com` to redeem the enrollment token and discover servers, and to `get.thundercompute.com` to download `libthunder` and the uninstaller; `32000-32199` over TCP to connect to same-zone GPU servers. |
