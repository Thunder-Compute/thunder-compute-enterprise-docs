Review these requirements before creating a server or client.

For CUDA feature support and known limitations, also review [Compatibility](/compatibility).

## Account and zone requirements

You need access to your organization in the [Thunder dashboard](https://app.thundercompute.com/). Thunder Compute Enterprise does not currently offer self-service onboarding. If you cannot access your organization after being invited, contact [support@thundercompute.com](mailto:support@thundercompute.com).

Create a zone or select an existing one from the **Zones** tab. Servers and clients must belong to the same zone to communicate with each other.

## Network performance recommendations

For best performance between servers and clients in a zone, use a network with:

- Round-trip latency below `2 ms`
- Throughput above `5 Gbps`

## Server requirements

A server is a machine with an NVIDIA GPU that provides GPU capacity to clients in its zone.

### System requirements

The server must have:

- An NVIDIA GPU
- NVIDIA driver 610 or newer. Thunder currently pins version `610.43.02`.
- Root or `sudo` access
- `curl` available in `PATH`

Mapped, pinned, and managed memory requires a Thunder-patched NVIDIA kernel module on each server. This includes `cudaHostAlloc`, `cudaHostRegister`, `cudaMallocManaged`, and the equivalent CUDA Driver API calls.

Other allocation types work without the patched module. If the module is unavailable, only mapped, pinned, and managed memory allocations fail.

### Network requirements

Configure the following access before installing Thunder on a server.

#### Ingress

| Port | Protocol | Reason |
| --- | --- | --- |
| `32000-32199` | TCP and UDP | Communication between servers in the same zone and client-facing GPU traffic. Scope this range to the server and client networks in the zone. |

#### Egress

| Port | Protocol | Reason |
| --- | --- | --- |
| `2096` | TCP | Registration, heartbeat, check-in, and telemetry traffic to Thunder's control plane. |
| `443` | TCP | Downloading and updating the `thunderd`, `thunder`, and `libthunder` binaries from `get.thundercompute.com`. |

## Client requirements

A client is a machine, VM, or container that runs CUDA workloads using GPUs from servers in the same zone. It does not need a local GPU.

### System requirements

The client installer requires:

- Linux on an `x86_64` processor
- Root or `sudo` access
- `curl`, `sha256sum`, `install`, and `sed` available in `PATH`

Clients do not need a local NVIDIA driver or a local GPU.

### Network requirements

Configure the following access before installing Thunder on a client.

#### Ingress

Clients do not require inbound ports for Thunder.

#### Egress

| Port | Protocol | Reason |
| --- | --- | --- |
| `2096` | TCP | Redeeming the enrollment token and discovering servers through `api.thundercompute.com`. |
| `32000-32199` | TCP | Connecting to GPU servers in the same zone. |
| `443` | TCP | Downloading `libthunder` and the uninstaller from `get.thundercompute.com`. |
